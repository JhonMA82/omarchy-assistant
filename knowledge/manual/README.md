# Notas manuales

Este directorio contiene notas y apuntes manuales que no siguen el formato estructurado de `knowledge/solved/`: referencias, procedimientos en estudio o documentación de apoyo. La diferencia clave con `knowledge/solved/` es que allí solo se registran soluciones ya validadas por el usuario y consolidadas con `/solved`, con causa, verificación y commit asociado. Lo que está en `manual/` no implica estado validado.
